Expand description

Os factories dos services.

Cada método devolve impl Trait — contrato, nunca tipo concreto. O tipo real é innomeável: só existe depois da monomorfização, e é exatamente por isso que a apresentação não consegue depender dele.

Os services são reconstruídos a cada chamada. Isso é barato de propósito: eles não guardam estado, e os recursos caros — pool, caches — nasceram uma vez no crate::register() e chegam por clone.
