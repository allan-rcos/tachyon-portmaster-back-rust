Expand description

A implementação, genérica sobre os ports que consome.

Nada de Arc<dyn>: os tipos concretos chegam do provider e o compilador monomorfiza o grafo inteiro. Um caso de uso que não pudesse ser montado seria erro de compilação, não surpresa no primeiro request.
