Source§

async fn get(&self, query: GetAccountQuery) -> Result<AccountView, AccountError>

O perfil de quem está na sessão.

Não confere permissão: a conta é do próprio usuário, e a sessão já provou quem ele é. Responde InvalidCredentials se ela não existe mais — a conta some entre a emissão do token e o pedido quando o usuário é removido, e o token continua assinado sem descrever ninguém.

Source§

async fn change_password( &self, command: ChangePasswordCommand, ) -> Result<(), AccountError>

Troca a senha do próprio usuário.

A senha atual é exigida mesmo com a sessão válida: um token roubado não deve bastar para trocar a senha e expulsar o dono.
