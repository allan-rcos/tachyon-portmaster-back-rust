A orquestração de contêineres.

§As permissões são privadas

Os slugs abaixo são contrato: já existem em papéis gravados no banco de quem roda a versão PHP, e renomear qualquer um revoga silenciosamente o acesso de quem o tinha. São const privadas porque uma permissão pertence a exatamente um caso de uso — é ele quem a compara com o UserContext, e não há segundo lugar no sistema que precise vê-la. O boot as registra chamando declare_permissions, sem nunca lê-las.
