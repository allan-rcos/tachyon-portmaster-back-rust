fn validate( &self, context: &UserContext, ) -> impl Future<Output = Result<Box<dyn User>, AppError>> + Send

Reconfere que a sessão ainda descreve alguém.

O token é auto-contido e válido até expirar, então ele continua sendo aceito depois de o usuário ser removido ou ter os papéis trocados. Isto é o que confronta a afirmação do token com o banco, para quem quiser pagar a consulta.
