Expand description

A entity, que é também a linha de containers.

Fields§

§id: EntityId

A identidade, nas duas formas.

§code: String

O código do contêiner.

§current_weight: f64

Peso embarcado, em quilos.

§max_capacity: f64

Teto de peso.

§status: ContainerStatus

O status, já como enum de domínio — a coluna guarda o índice.

O Decode valida o índice na leitura: um valor que não corresponde a variante nenhuma é uma linha que o schema não deveria admitir, e escolher uma variante por aproximação afirmaria um estado que o banco não guardou.

§created_at: DateTime<Utc>

Quando a linha nasceu, em UTC.

§updated_at: DateTime<Utc>

Quando a linha mudou pela última vez, em UTC.

§deleted_at: Option<DateTime<Utc>>

Quando foi removida, ou None se ativa — o soft-delete.
