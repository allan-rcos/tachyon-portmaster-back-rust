Expand description

A entity, que é também a linha de users.

Os papéis chegam separados: vêm de user_roles e são carregados pelo repositório, não pela linha de users.

Fields§

§id: EntityId

A identidade, nas duas formas.

§name: String

Nome de exibição.

§email: String

E-mail, que também é a credencial de login.

§password_hash: String

O hash Argon2, como está gravado.

§roles: Vec<Box<dyn Role>>

Os papéis já hidratados.

Não é coluna: os papéis vêm de user_roles, numa segunda consulta, e são anexados por with_roles. Um usuário sem eles não está completo — é o repositório que fecha isso, porque é ele quem sabe consultar.

É este campo que obriga o [FromRow] a ser escrito à mão: o derive lê a linha campo a campo e não tem como pular um.

§created_at: DateTime<Utc>

Quando a linha nasceu, em UTC.

§updated_at: DateTime<Utc>

Quando a linha mudou pela última vez, em UTC.

§deleted_at: Option<DateTime<Utc>>

Quando foi removida, ou None se ativa — o soft-delete.
