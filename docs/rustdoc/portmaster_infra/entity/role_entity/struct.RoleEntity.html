Expand description

A entity, que é também a linha de roles.

O FromRow é derivado: cada conversão que se escreveria à mão no corpo de um from_row é atributo do campo que a exige — o id e os instantes pelo Decode, as permissões pelo json.

Fields§

§id: EntityId

A identidade, nas duas formas.

§name: String

Nome do papel.

§permissions: Vec<String>

Os slugs concedidos, na coluna JSON.

Uma coluna ilegível é linha corrompida, e o json a faz falhar. Assumir lista vazia silenciosamente seria revogar todas as permissões do papel, que é o pior desfecho possível.

§created_at: DateTime<Utc>

Quando a linha nasceu, em UTC.

§updated_at: DateTime<Utc>

Quando a linha mudou pela última vez, em UTC.

§deleted_at: Option<DateTime<Utc>>

Quando foi removida, ou None se ativa — o soft-delete.
