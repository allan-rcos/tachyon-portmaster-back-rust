Os factories da infra.

Cada método devolve impl Trait — contrato, nunca tipo concreto. Os recursos base (pool, caches) nascem uma vez no crate::register() e são entregues por clone barato; os serviços são reconstruídos a cada chamada, porque são structs de campos leves e custam praticamente nada.

Não há unit_of_work aqui: quem a entrega é o MasterScope::run, a partir das camadas que o linker registrou. O que a infra injeta é o handle que abre a transação, e ele é detalhe de cada repositório.
