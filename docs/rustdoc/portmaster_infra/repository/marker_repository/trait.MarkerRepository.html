Expand description

Marcadores booleanos com prazo.

A infra nunca sabe o que uma marca significa — só que é um booleano com validade, num grupo conhecido.

fn is_valid( &self, group: &str, key: &str, ) -> impl Future<Output = Result<bool>> + Send

Se a marca está válida.

Marca inexistente, expirada ou desligada respondem igual: false. Quem pergunta quer saber se pode seguir, não por que não pode.
