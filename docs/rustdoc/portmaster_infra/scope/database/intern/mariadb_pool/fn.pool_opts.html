Fixa o teto de conexões simultâneas.

O piso é zero, e não o padrão do driver: uma instalação pequena não deve segurar dez conexões ociosas contra um servidor que talvez nem as ofereça. O teto é decisão de arquitetura, escolhida por feature de compilação — ver POOL_MAX_CONNECTIONS.
