Os read models: um por consulta, POD e por valor.

Uma View é o formato que a leitura devolve — sem dyn, sem Box, sem objeto de domínio. Guardar o tempo como i64 de epoch em ms, o enum como i32 de índice e o id como String base62 faz a View atravessar até a apresentação sem que nenhuma camada do meio precise reinterpretá-la.
