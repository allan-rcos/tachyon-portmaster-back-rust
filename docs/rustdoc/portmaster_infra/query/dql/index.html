Os descritores de consulta: um por consulta.

Um DQL não executa nada: ele descreve a consulta e sabe ler o resultado. Quem executa é o QueryRepository, e é essa separação que faz uma consulta nova não tocar o executor.

Os *_reader são a exceção proposital: leitura de linha compartilhada entre duas consultas que projetam o mesmo recorte.
