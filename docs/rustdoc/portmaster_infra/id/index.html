Os dois geradores de id que não são identidade de entidade.

Identidade de entidade nasce no domain, no TableModule. Estes dois são da borda: o refresh token precisa ser opaco e imprevisível, o request_id precisa ordenar no tempo para agrupar log. Nenhum dos dois é regra de negócio, e por isso moram aqui.
