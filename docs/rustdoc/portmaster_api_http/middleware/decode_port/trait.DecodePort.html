Expand description

Lê um VO de requisição do formato que esta requisição anunciou.

Genérica sobre o VO pela mesma razão da EncodePort, e com a mesma consequência: quem chama não descobre de qual formato o corpo veio.

Um formato que não sabemos ler nunca chega aqui — quem o recusa é o middleware, com 415, antes de o corpo ser lido.
