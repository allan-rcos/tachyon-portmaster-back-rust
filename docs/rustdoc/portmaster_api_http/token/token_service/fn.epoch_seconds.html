O agora, em epoch de segundos.

O .clippy.toml bane SystemTime::now para forçar um relógio injetado, e a intenção é boa: relógio injetado é o que torna regra de negócio testável. Só que este uso não é regra de negócio — é o exp/iat de um JWT, que por definição precisa do relógio de parede real, o mesmo que o cliente e qualquer outro verificador vão consultar. Um relógio de mentira aqui produziria um token que só é válido para quem compartilha a mentira.

Vale registrar o que falta: não existe port de relógio nesta arquitetura — tmp/ o menciona, nenhum crate o declara. Se ele aparecer, este é um dos pontos a revisitar, e a decisão acima é que continuaria valendo.
