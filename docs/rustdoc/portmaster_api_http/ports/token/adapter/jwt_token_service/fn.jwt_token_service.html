Monta o serviço de token a partir da configuração.

Devolve o tipo concreto porque o provider precisa guardá-lo num static, e um static exige um tipo com nome — um impl Trait não é um. Nem a função nem o tipo saem do módulo ports::token, e quem entrega o contrato é o provider.
