Struct ControllersProvider

pub(crate) struct ControllersProvider;
Expand description

Os controllers, já costurados com os services que consomem.

Construídos uma vez no boot e clonados por requisição, ao contrário dos services, que são reconstruídos a cada chamada. É a diferença que justifica o self por valor nos handlers: um controller é um punhado de handles, e clonar é o que o axum faz com todo handler.

pub(crate) fn install_environment(environment: String)

Instala o nome do ambiente que o /info responde.

É a única coisa que um controller carrega da configuração desta camada, e é por isso que ele entra sozinho: trocar o ambiente não tem por que obrigar a passar o segredo do token junto. Quem instala o segredo é o TokenProvider, que é quem o consome.
