A memória residente do processo, em MiB.

Lida do /proc, que é onde o número existe sem custar uma dependência. Fora do Linux — ou se o arquivo mudar de forma — responde 0: o campo é informativo, e derrubar o /info por não saber quanta memória se usa tornaria inútil a rota que serve justamente para dizer que o servidor está de pé.
