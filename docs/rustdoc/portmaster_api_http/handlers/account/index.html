/account — o que um usuário faz com a própria conta.

Nenhuma destas rotas pede permissão: o alvo é sempre quem está agindo, e o id vem do contexto da sessão — nunca do corpo. É o app que garante isso; aqui só se repassa o contexto.

§Por que a escrita relê antes de responder

PUT /account responde com o perfil, que carrega quantos usuários cada papel tem. Esse número é consulta, não regra: o objeto de domínio que a escrita devolve não o conhece, e publicá-lo zerado seria informar um valor errado em vez de nenhum. Reler pelo lado de leitura é o que mantém a resposta igual à do GET que vem logo depois.
