/manifests — embarcar e desembarcar carga.

Duas rotas com o mesmo formato de corpo e a mesma resposta; o que muda é o sentido do movimento. Não há GET: o manifesto de um contêiner sai pelo resumo (GET /containers/summary), que é onde ele tem contexto.

§A resposta é o contêiner, não a linha movimentada

Quem embarcou já sabe o que embarcou — foi ele quem pediu. O que ele não sabe é o efeito: quanto o contêiner passou a pesar e se saiu de vazio, que é o que decide se o próximo passo é carregar mais ou selar. A mensagem acompanha por contrato do schema.
