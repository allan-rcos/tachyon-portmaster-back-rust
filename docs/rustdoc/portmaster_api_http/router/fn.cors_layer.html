A política de CORS.

Sem origens configuradas, a camada não libera nada — é o padrão seguro, e o que vale quando a API e o front saem do mesmo host. Com origens, libera credenciais: a sessão viaja em cookie, e sem allow_credentials o navegador não o mandaria.
