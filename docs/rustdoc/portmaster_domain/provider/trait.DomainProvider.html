Os factories do domain.

Cada método devolve impl Trait: o consumidor recebe o contrato, nunca o tipo concreto. O despacho é estático — o compilador monomorfiza o grafo inteiro, então um serviço que não pode ser construído é erro de compilação, não surpresa em produção.
