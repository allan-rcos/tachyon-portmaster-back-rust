pub(crate) fn set_weight_and_status( &mut self, weight: f64, status: ContainerStatus, )

Substitui peso e status juntos, marcando a alteração.

Os dois andam sempre juntos — carregar muda o peso e pode mudar o status, descarregar até o vazio faz as duas coisas — e separá-los abriria espaço para um contêiner com peso zero marcado como Loading.
