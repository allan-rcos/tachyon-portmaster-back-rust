Expand description

A implementação do domínio de User.

Construída e alterada apenas pelo UserTM, que é quem conhece as regras. Nem o UseCase nem o repositório a instanciam.

Fields§

§id: String

Identidade, em base62.

§name: String

Nome de exibição.

§email: String

E-mail, que também é a credencial de login.

§password_hash: String

O hash Argon2 da senha.

Nunca a senha em claro, e nunca publicado no fio: a tabela de resposta não tem onde pô-lo, e é isso que garante que não vaze.

§roles: Vec<Box<dyn Role>>

Os papéis concedidos; a união das permissões deles é o que o usuário pode.

§created_at: DateTime<Utc>

Quando foi criado, em UTC.

§updated_at: DateTime<Utc>

Quando mudou pela última vez; o set_* o move.

§deleted_at: Option<DateTime<Utc>>

Quando foi removido, ou None se ativo — o soft-delete.
