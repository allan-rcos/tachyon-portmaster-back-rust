A implementação, genérica sobre os helpers que recebe.

Nem o gerador de id nem o hasher são instanciados aqui: chegam injetados pelo factory do provider, o que os torna substituíveis em teste sem que nada além do domínio saiba que existem.

Examina a senha.

Exige minúscula, maiúscula, dígito e comprimento mínimo. A mensagem enumera as quatro condições de uma vez porque devolver “falta um dígito”, depois “falta uma maiúscula”, faria o usuário descobrir a regra por tentativa e erro.
