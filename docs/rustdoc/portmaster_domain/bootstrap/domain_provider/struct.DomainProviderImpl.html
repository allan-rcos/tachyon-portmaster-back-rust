fn database_id_generator( &self, ) -> impl DatabaseIdGenerator + Clone + use<> + 'static

Serve o gerador de id de entidade.

A impl é escolhida por feature de compilação — decisão de arquitetura, resolvida no build, sem ramo em runtime. Os parâmetros de identidade vêm dos segredos.

Não está no DomainProvider de propósito: quem emite identidade de entidade é o TableModule, e um gerador destes fora do crate permitiria montar uma linha sem passar pela regra que a valida.
