Expand description

Alguém que faz login, com os papéis que carrega.

Permissão nunca é concedida direto a uma pessoa — ela vem pelo papel, e é a lista de slugs do papel que o guarda de autorização confere.

O trait é somente-leitura: só existem getters. Quem o recebe consegue ler o usuário mas não alterá-lo, e é isso que impede o app ou o api de mudarem um e-mail sem passar pela validação do TableModule.
