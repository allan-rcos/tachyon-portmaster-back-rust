3/// Gera um id opaco e imprevisível.
4///
5/// O refresh token é o caso: ele precisa ser impossível de adivinhar, que é o
6/// oposto do requisito de um id de entidade — este último ordena por tempo
7/// justamente para ser previsível ao índice do banco.
8/// Os dois pedem `Clone + Send + Sync + 'static` pelo mesmo motivo que
9/// [`LoggerFactory`](crate::logging::LoggerFactory): quem os consome é um
10/// `tower::Layer`, e o axum exige que um layer seja clonável e compartilhável
11/// entre tarefas. Exigir aqui, e não no ponto de uso, é o que evita a
12/// apresentação descobrir a restrição como um erro de trait a três camadas de
13/// distância — nenhum gerador tem estado, então nenhum paga por isso.
14pub trait RandomIdGenerator: Clone + Send + Sync + 'static {
15    /// Um id aleatório novo.
16    fn next(&self) -> String;
17}
