1//! Os nomes das variáveis de ambiente.
2
3/// Os nomes das variáveis, exatamente como o PHP as lia.
4///
5/// São contrato com o `docker-compose.yml` e com quem já roda o sistema:
6/// renomear qualquer uma quebra um deploy existente em silêncio, porque o valor
7/// simplesmente cai no padrão.
8///
9/// Struct-namespace e não um `mod` de consts soltas: o módulo já é o arquivo, e
10/// agrupá-las num tipo é o que mantém um export só por arquivo.
11pub(crate) struct Env;
12
13impl Env {
14    /// `APP_HOST`
15    pub(crate) const HOST: &str = "APP_HOST";

18    /// `APP_ENV`
