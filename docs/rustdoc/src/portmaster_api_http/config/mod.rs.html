1//! Os segredos e knobs de runtime desta apresentação.
2//!
3//! Esta camada é a **única** que lê ambiente. Ela monta as structs de segredo de
4//! todas as camadas — [`portmaster_app::AppSecrets`] chega pronta ao `register`,
5//! que a distribui para dentro. As camadas internas nunca leem uma variável:
6//! recebem o que precisam por argumento, e por isso são testáveis sem preparar
7//! ambiente nenhum.
8//!
9//! ## O que é runtime e o que é build
10//!
11//! Aqui só entra **segredo ou identidade de deploy**: senha do banco, segredo do
12//! JWT, host/porta, quem é este servidor na composição do Snowflake. Knobs de
13//! **arquitetura** — tamanho de pool, capacidade e TTL dos caches, estratégia de
14//! id — são features de compilação, e não têm variável correspondente de
15//! propósito: um `if` em produção sobre uma decisão de arquitetura é um bug
16//! esperando o dia de errar.
17
