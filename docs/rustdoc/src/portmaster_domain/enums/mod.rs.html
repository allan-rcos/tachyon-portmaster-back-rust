1//! Valores imutáveis que mudam a regra de negócio.
2//!
3//! Um valor que o domínio nunca altera e que decide o comportamento é um enum —
4//! não uma linha de banco nem uma string solta. Fechá-lo no código é o ponto:
5//! um `match` sobre o status obriga o compilador a apontar cada lugar que
6//! esqueceu de tratar um estado novo, o que uma string jamais faria.
7//!
8//! A representação numérica de cada variante é o que vai ao banco e ao fio. Os
9//! valores são fixos e **não podem ser reordenados** — mudar o índice de uma
10//! variante reinterpreta silenciosamente as linhas já gravadas.
11
