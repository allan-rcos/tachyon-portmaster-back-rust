3/// Gera o id de uma entidade persistida, já compactado em base62.
4///
5/// O id vira chave primária, então ele ordena por tempo: o índice cresce pela
6/// ponta em vez de fragmentar. É o requisito que separa este sabor dos outros
7/// dois — usá-lo onde o valor nunca chega a uma tabela desperdiça a única coisa
8/// que ele tem de caro.
9///
10/// O `&self` não é um detalhe: o gerador é compartilhado por todas as threads do
11/// processo. É diferente do modelo de processos forkados, em que cada worker
12/// tinha o seu próprio contador e a unicidade dependia de nunca repetir o par
13/// cluster/server.
14pub(crate) trait DatabaseIdGenerator {
15    /// Um id novo, único e crescente no tempo.
16    fn next(&self) -> String;
17}
